# Release Process

## SDK Release Notes

Include:

- Public class, method, package, and version changes.
- Backend API contract assumptions.
- TypeScript SDK and Genetec plugin alignment notes.
- Migration notes for breaking changes.
- NuGet/package validation status.

## Validation

- Build the solution.
- Validate package contents for release changes.
- Coordinate downstream Genetec plugin updates when public SDK behavior changes.
